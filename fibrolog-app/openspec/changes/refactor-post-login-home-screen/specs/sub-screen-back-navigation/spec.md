## ADDED Requirements

### Requirement: Sub-Screen Back Navigation
The system SHALL provide a "back to home" button in the header of all sub-screens accessible from the home page.

#### Scenario: Sub-screen displays back to home button
- **WHEN** the user navigates to a sub-screen from the home page
- **THEN** a button to navigate back to the home screen SHALL be displayed in the header.

#### Scenario: User navigates back to home from sub-screen
- **WHEN** the user is on a sub-screen
- **AND** the user taps the "back to home" button in the header
- **THEN** the user SHALL be navigated back to the home screen.
