## ADDED Requirements

### Requirement: Self-care tips integration
The Progress screen SHALL include a dedicated section for self-care suggestions after the insights section.

#### Scenario: Visualizing self-care tips on Progress screen
- **WHEN** the Progress screen is fully loaded
- **THEN** the system SHALL display the "Dicas de Autocuidado" section header
- **AND** the system SHALL render the list of available self-care suggestion cards
